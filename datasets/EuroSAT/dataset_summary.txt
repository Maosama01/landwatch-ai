EuroSAT (RGB) - stratified train / val / test split used by LandWatch AI
=======================================================================
Source     : EuroSAT, Helber et al., "EuroSAT: A Novel Dataset and Deep Learning Benchmark for
             Land Use and Land Cover Classification", IEEE JSTARS 12(7), 2019.
             Zenodo record 7711810 (EuroSAT_RGB.zip), MIT licence, MD5 verified on download.
Imagery    : Sentinel-2 RGB bands, 64 x 64 px JPEG tiles at 10 m ground sample distance (640 m x 640 m).
Images     : EuroSAT_RGB/<Class>/<Class>_<n>.jpg (not redistributed in this repository).
Created    : 2026-11-19 by com.landwatch.deeplearning.eurosat.EuroSatSplit
Method     : per class, files sorted by <n>, shuffled with java.util.Random(42) (one generator,
             classes in alphabetical order); first round(0.70 n) -> train, next round(0.15 n) -> val,
             rest -> test.
Class index: alphabetical order of the class folder names (0-based).
Files      : splits/train.csv, splits/val.csv, splits/test.csv; columns path,class_name,class_index;
             paths are relative to datasets/EuroSAT/.
