# Dataset card: data used by LandWatch AI

This card follows the questions of "Datasheets for Datasets" (Gebru et al., 2021) for the three image sources the project uses. None of the images are redistributed in this repository; only split files, metadata and derived reports are committed.

## LEVIR-CD

**Motivation.** A large public benchmark for building-change detection in very-high-resolution images, released with the STANet model.

**Composition.**
- 637 pairs (A = earlier date, B = later date) with one mask each; official split 445 train, 64 val, 128 test pairs.
- According to the authors, the images come from 20 regions in several cities of Texas, USA. 31,333 building-change instances are annotated.
- Change pixels are rare: 4.65 % of all mask pixels. At patch level change is common: 4,538 of the 10,192 tiles (44.5 %) contain some change.
- The labels cover buildings only. Roads, vegetation, water and deforestation are not labelled, so a model trained here says nothing about them.

**Collection and labelling.** Done by the dataset authors (Google Earth imagery, manual annotation). We did not relabel anything.

**Quality issues we found.** 32 of the 637 masks contain stray non-binary values (709 pixels of 156 or 254 in total). The project keeps them unchanged and treats every value above 0 as change (`datasets/LEVIR-CD/processed_256/preparation_report.txt`).

**Preprocessing in this project.** `python_dataprep/tile_levir_dataset.py` cuts every 1024×1024 image into 16 non-overlapping 256×256 tiles: 10,192 tile triplets (7,120 train, 1,024 val, 2,048 test), 30,576 files. An independent check compared every tile with its source crop: 0 differences. The official split is kept, so tiles from one image never land in two splits. Normalisation constants come from TRAIN tiles only.

**Uses here.** Training (train split), checkpoint, threshold and ablation choices (val split), and a single final evaluation per model (test split). The classical baseline needs no training and is evaluated on the full-resolution val and test images.

**Things to keep in mind.** All images are from one region and one source, so performance elsewhere (other countries, sensors, seasons or resolutions) is unknown. Imagery of private property is involved; the dataset's academic-use terms apply to the committed weights too.

## EuroSAT (RGB)

**Motivation.** A land-use / land-cover benchmark built from free Sentinel-2 data.

**Composition.** 27,000 labelled 64×64 patches in 10 classes: AnnualCrop, Forest, HerbaceousVegetation, Highway, Industrial, Pasture, PermanentCrop, Residential, River and SeaLake (2,000–3,000 per class), from 34 European countries according to the authors. We use the RGB version, not the 13-band multispectral one.

**Preprocessing in this project.** A stratified 70/15/15 split with seed 42 (`EuroSatSplit`): 18,900 train, 4,050 val and 4,050 test images. The split files are committed in `datasets/EuroSAT/splits/`; a check confirms the three parts are disjoint and together complete.

**Uses here.** The ResNet classifier (and its dashboard page) and the VAE experiment. Both train on TRAIN, choose their checkpoint on VAL and are evaluated once on TEST. The VAE does not use the class labels for training; they are only used to report per-class results.

**Things to keep in mind.** 10 m pixels: a 64×64 patch covers 640 m × 640 m, so the classifier labels whole scenes, not single buildings. It is not valid on 0.5 m LEVIR-CD imagery, and the dashboard refuses to classify LEVIR-CD pairs.

## Synthetic demo pair

`src/main/resources/com/landwatch/sample_data/siteA_*.bmp` is generated by a script so the dashboard has something to show without any download. It is **not satellite imagery**, no accuracy is claimed on it, and it is never used for training or evaluation.
