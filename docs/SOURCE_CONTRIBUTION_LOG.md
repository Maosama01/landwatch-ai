# Source and contribution log

Where every part of LandWatch AI comes from. It separates what was written for this project from what was used from outside. References in square brackets are those of [REPORT.md, Section 14](../REPORT.md#14-references).

## 1. Datasets

| Dataset | Used for | Source and terms | In this repository |
|---|---|---|---|
| LEVIR-CD [1] | change detection: training, validation, test | Chen and Shi, 2020; <https://justchenhao.github.io/LEVIR/>; academic use only, Google Earth terms apply | no images; split metadata, derived reports and the weights trained on it |
| EuroSAT RGB [3] | land-use classifier and VAE | Helber et al., 2019; Zenodo record 7711810; MIT licence | no images except two small derived figures (`results/eurosat_vae/*.png`, `results/fundamentals/svd_low_rank.png`); split files |
| Synthetic demo pair | dashboard demo only | generated by `python_dataprep/generate_sample_satellite_pair.py` (this project) | yes; not satellite imagery |

## 2. Libraries and tools

All are used as libraries through their public APIs; none of their source code is copied into this repository.

| Library / tool | Version | Licence | Role |

| JUnit Jupiter | 5.10.2 | EPL-2.0 | tests |

Transitive dependencies (for example Gson and JNA, pulled in by DJL) keep their own licences.

## 3. Pretrained components

**None.** Every model in `models/` was trained from randomly initialised weights in this project. No pretrained backbone, checkpoint or embedding was downloaded.

## 4. Architectures and methods taken from the literature

The implementations are this project's own code; the designs come from the cited work.

| Component | Idea from | Implemented in |
|---|---|---|
| FC-Siam-diff change detector | Daudt, Le Saux and Boulch, ICIP 2018 [2] (U-Net [25]) | `deeplearning/FcSiamDiff.java`; documented deviations in REPORT §6.4.2 |
| Bottleneck Transformer | BIT, Chen, Qi and Shi, 2022 [28]; Transformer, Vaswani et al., 2017 [27] | `deeplearning/BitemporalTransformer.java` (simplified, not a copy of BIT) |
| ResNet classifier | He et al., 2016 [5] | `deeplearning/eurosat/EuroSatResNet.java`, `ResidualBlock.java` |
| Variational autoencoder | Kingma and Welling, 2014 [29] | `deeplearning/eurosat/EuroSatVae.java`, `VaeLoss.java` |
| Weighted BCE + soft Dice loss | Milletari et al., 2016 [20] | `deeplearning/BceDiceLoss.java` |
| Otsu threshold | Otsu, 1979 [4] | `geospatial/BaselineChangeDetector.java` |
| Backpropagation, optimisers, learning rules | [6]–[16] | `fundamentals/**` (plain Java) |
| One-sided Jacobi SVD | Hestenes, 1958 [30] | `fundamentals/math/SingularValueDecomposition.java` |
| Dataset and model cards | Gebru et al., 2021 [33]; Mitchell et al., 2019 [32] | `docs/` |

## 5. External code

To the team's knowledge, no source code was copied from other repositories, tutorials or Q&A sites into the project's Java or Python code. Where an algorithm follows a paper, the paper is cited above and in the code's Javadoc. If anyone finds otherwise, the source must be added here.
